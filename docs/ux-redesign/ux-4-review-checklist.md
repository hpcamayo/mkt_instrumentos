## Listing page (desktop, 1280/1440)

- [ ] Two columns: gallery, Especificaciones, Descripción, Reseñas left; title, marca/modelo, price, condition line, spec strip, WhatsApp, Guardar, trust line, seller card, report right
- [ ] No "Visto N veces" anywhere
- [ ] Only one "Contactar por WhatsApp"; no second button in the seller card; one "Ver la tienda"
- [ ] Gallery arrows, counter, thumbnails (six, then "+N"); clicking the photo opens the lightbox; Esc closes it and focus returns
- [ ] Especificaciones shows Tipo, Marca, Modelo, Condición and the attributes, no "No indicada"
- [ ] Reviews show "Nombre I.", "N de 5", the month, and "Mostrando las 5 más recientes de N" when there are more
- [ ] Related sections show four cards each and disappear when empty
- [ ] The strip underlines the listing's category

## Listing page (phone, 390)

- [ ] Back link, gallery swipes, four thumbnails then "+N"
- [ ] The bar at the bottom: WhatsApp, the heart, one line with "Consejos de seguridad"; it never covers a focused link
- [ ] In landscape (short screen) the bar is not fixed
- [ ] Sold listing: "Vendida", no bar, "Ver publicaciones similares", the historical line in the seller card

## Store page

- [ ] Verified store: breadcrumb "Inicio / Tiendas verificadas / …", banner strip only when uploaded, figures, WhatsApp at the right, strip marks "Tiendas verificadas"
- [ ] Section links jump to Publicaciones, Reseñas, Sobre la tienda
- [ ] Grid: 2 / 3 / 4 / 5 columns; pages of 24
- [ ] Sobre la tienda: Ubicación, Redes (only real links), Fotos del local (open the lightbox), Verificación, Reportar tienda
- [ ] Plain Tienda: no banner, "Tienda" tag, no breadcrumb middle item, "Laria aprobó esta tienda…"
